# Working on FOXTAIL

## Git workflow

For every change made here, always:

1. Open a pull request for the change (never push straight to `main`).
2. Merge the pull request once it's ready — don't leave it open waiting for manual merge.
3. Give the GitHub Pages link back at the end: https://scottyfncodes.github.io/FOXTAIL/

`main` auto-deploys to GitHub Pages via `.github/workflows/deploy-pages.yml`, so a merge is what ships the change.
